; ═══════════════════════════════════════════════════════════════
;  CHIRON RISING — Future Society repricing (OPTIONAL)
; ═══════════════════════════════════════════════════════════════
;
; Apply with:  ./install.sh --se-rebalance
; Undo with:   ./install.sh          (a plain reinstall restores stock alphax.txt)
;
; This is OFF by default and is the only part of the mod that changes the rules
; rather than the words. It also changes a game already in progress: SMAC saves
; store which social model you picked, not what that model does, so a running
; game silently picks up the new effects the next time it loads. Finish a game
; before applying it, or apply it and accept that.
;
;
; WHY
;
; Count the ± pips on every row of the stock #SOCIO table:
;
;     Police State    +4/-2      Free Market   +2/-8      Power       +4/-2
;     Democratic      +4/-2      Planned       +3/-2      Knowledge   +3/-2
;     Fundamentalist  +3/-2      Green         +4/-2      Wealth      +2/-2
;     Cybernetic      +6/-3      Eudaimonic    +6/-2      Thought Control +6/-3
;
; Every Future Society is +6 gross where nothing else in the game clears +4, and
; Eudaimonic at +6/-2 is the best ratio on the table. That is not three options
; balanced against each other -- it is a row that is strictly better than the
; row above it, which is why the late game feels the same whichever one you take.
; They are not a choice, they are a reward for surviving to the tech.
;
; So the fix is not to shuffle them against one another. It is to price the whole
; row at the +4/-2 the rest of the game is written in, and to make the penalty
; land somewhere that still hurts by the time you get there.
;
;
; FIRST, THE THING THAT CHANGES THE ARITHMETIC
;
; TWO OF THE THREE PENALTIES ARE NOT PAID AT ALL. social_calc() in faction.cpp
; zeroes EVERY negative on a Future Society model when the faction holds one
; project:
;
;     Cybernetic       + Network Backbone  -> all negatives become 0
;     Thought Control  + Cloning Vats      -> all negatives become 0
;     Eudaimonic                           -> no such clause; it always pays
;
; So the stock row is worse than the pip count suggests. Cybernetic and Thought
; Control are +6/0 for whoever lands the project, and since a project is
; singular, everyone else keeps paying. Eudaimonic's +6/-2 is not the outlier it
; looks like -- it is the only one of the three whose cost is real, which is a
; reason to price it GENTLY, not to punish it further.
;
; Note the clause zeroes any negative, not a specific one. Moving a penalty from
; POLICE to GROWTH does not make it unbuyable; it changes what you lose until
; the project lands, and for most factions that is the whole game.
;
;
; WHAT CHANGES
;
; Cybernetic loses ++PLANET and takes --GROWTH beside --POLICE.
;     Losing ++PLANET is the point of the edit: Green stops being a stepping
;     stone on the way to a strictly better version of itself. --GROWTH is the
;     right cost thematically -- a society that has handed itself to its
;     machines optimises, it does not breed -- and it bites for every faction
;     that never builds the Backbone.
;
; Thought Control loses ++PROBE, --SUPPORT softens to two pips, --RESEARCH is
; added.
;     POLICE and MORALE are its identity and both stay. What total obedience
;     should cost is inquiry. Cloning Vats still voids both, as it always did.
;
; Eudaimonic loses ++INDUSTRY and keeps --MORALE alone.
;     ONE penalty, not two, precisely because it is the one that cannot be
;     voided. Abundance was paying a single pip for three; now it pays a single
;     pip for two, permanently, which is a fairer deal than the other two get
;     the moment their project completes.
;
; So the row becomes:
;
;     Cybernetic       +4/-4    -- voided entirely by Network Backbone
;     Eudaimonic       +4/-2    -- permanent, and the standard rate
;     Thought Control  +4/-4    -- voided entirely by Cloning Vats
;
; against +4/-2 for Police State, Democratic, Green and Power. Gross is now the
; same as the rest of the table for all three; the two with an escape hatch pay
; double until they reach it, and the one with no escape pays exactly what every
; other row pays, forever. The row stops being strictly better than the row
; above it.
;
;
; WHAT DOES NOT CHANGE, AND CANNOT
;
; The eleven effect COLUMNS (ECONOMY, EFFIC, SUPPORT, TALENT, MORALE, POLICE,
; GROWTH, PLANET, PROBE, INDUSTRY, RESEARCH) are hardcoded engine semantics.
; Thinker's own AI reads them directly -- mod_social_ai() in faction.cpp reasons
; about SE_GROWTH against GrowthPopBoom, projects pop booms per base, and weighs
; defence off p->defense_modifier. You can rename what a column is CALLED; you
; cannot change what it MEANS. The #SOC* blocks below the table are labels for
; integer levels whose behaviour is compiled in, not a place to redefine the
; rungs.
;
; The rows are the opposite: entirely open, and the AI comes along for free,
; because it evaluates the resulting effect vector rather than the name. That
; asymmetry is the whole reason this edit is three lines of text and no code.
;
;
; THE REPLACEMENT ROWS
;
; install.sh replaces the three lines in the installed alphax.txt's #SOCIO block
; that begin with these names. Nothing else in the file is touched.

Cybernetic,      DigSent, ++EFFIC,  ++RESEARCH, --GROWTH, --POLICE
Eudaimonic,      Eudaim,  ++GROWTH, ++ECONOMY,  --MORALE
Thought Control, WillPow, ++POLICE, ++MORALE,   --SUPPORT, --RESEARCH
