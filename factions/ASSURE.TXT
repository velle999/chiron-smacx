; A Chiron Rising faction. Drop this file in the game directory alongside
; the stock faction files; the faction picker reads the directory.
;
; THE ARGUMENT: every other faction on Planet announces what it is. The
; Assurance holds that a position stated is a position surrendered, and that
; what actually binds people is not sincerity but consideration — the signed
; thing, the thing with a price on it. So it lies constantly and breaks
; nothing. Its word is worthless; its signature is good. It argues that
; everyone else confuses the two out of sentimentality, and pays for it.
;
; MECHANICALLY the deception is NOT in this file — it is in the diplomacy
; layer, where Vashti's persona carries a directive to overstate her strength
; and understate her need. That is the whole point of the faction: a scripted
; lie is read once and recognised forever, and a generated one has to be
; weighed against the map every single time. What is in this file is a
; negotiator: rich, superb at the Council, and unable to hold a population
; that is never told anything true.
;
; The lie is bounded by the engine, not by good intentions. Chiron decides the
; WORDS and never the OUTCOME, so a claim never changes what a pact does; and
; the mandatory-value check discards any reply that misstates the technology
; or the credits actually on the table. She can only lie about herself.
;
; NOTE ON THE STATS: `VOTES, 2` is the Peacekeepers' own value, so that one is
; known good. `---POLICE` is the untested number here — it is meant to be a
; real cost and may be too punishing next to `+ECONOMY`. If drone riots make
; the faction unplayable rather than difficult, `--POLICE` is the fallback and
; costs nothing but a degree of the argument.
;
